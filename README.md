# 駅から坂道マップ

物件の住所と最寄り駅を入れると、等高線つきの地図・徒歩ルート・高低差グラフを表示する静的Webサイトです。
（住宅検索プロジェクトのステップ1）

## できること
- 住所 → 位置（国土地理院 住所検索API）
- 駅名 → 位置（OpenStreetMap Nominatim、物件に一番近い同名駅）。空欄なら2km以内の最寄り駅を自動検索（Overpass API）
- 徒歩ルート（FOSSGIS OSRM foot）。取れないときは直線で代用
- 標高：国土地理院 標高タイル（5mメッシュ→10mメッシュの順）からルート上10m間隔で取得
- 等高線：同じ標高タイルからブラウザ内で描画（高低差に応じて1/2/5/10m間隔、5本ごとに太線）
- 駅→家（帰り道）／家→駅（行き道）の切り替え、登り合計・最大勾配・急な登りの長さ
- 徒歩分は不動産表記と同じ80m/分・端数切り上げ。「坂を考えた目安」はTobler の歩行速度式で補正
- 家・駅のピンはドラッグで位置を直せます。URLに `?addr=…&st=…` を付けると共有できます

## 動かし方
ビルド不要です。フォルダごと静的ホスティング（GitHub Pages など）に置くだけで動きます。
手元で試すなら `python3 -m http.server` を実行して http://localhost:8000 を開きます。
